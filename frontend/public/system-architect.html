Frontend Technologies

React + Vite

Core

Vite is the build tool making development lightning fast. React powers the component-based UI. Vite handles bundling assets for production.

@tanstack/react-virtual

Optimization

Crucial for the Super-Admin Dashboard.

Why? Instead of rendering 5,000 table rows (which freezes the browser), it only renders the 10 rows visible on the screen. Massive performance boost for the Audit Log.

@clerk/clerk-react

Auth

Handles authentication securely. Provides ready-made Login/Signup components and manages session tokens automatically.

Tailwind CSS

Styling

Utility-first CSS framework. Used to rapidly build custom, responsive designs without leaving the HTML/JSX.

Backend Technologies

Express.js (Node)

Core

The minimalist web framework handling API routing, middleware execution, and HTTP requests.

Redis (redis package)

Optimization

In-memory caching database.

Why? When 2,000 students open the app simultaneously, fetching from MongoDB would crash the DB. Redis serves the announcements from RAM instantly.

Mongoose & @mongodb-js/zstd

Database

Mongoose is the ORM for MongoDB. Zstd is the compression algorithm.

Why Zstd? Compresses network traffic between the Node server and MongoDB Atlas, reducing latency and bandwidth costs by up to 70%.

compression & sharp

Media/Network

Network and media optimization tools.

Why? `compression` uses Brotli/Gzip to shrink API JSON responses. `sharp` takes heavy images (like 5MB PNGs) and converts them into tiny, optimized WebP files before uploading.

Crucial System Mechanisms

🔄 Infinite Scrolling

Using the browser's native `IntersectionObserver` on the frontend, combined with `page` & `limit` queries on the backend. Only loads 20 notices at a time to save data.

🔔 Push Notifications

Uses the `web-push` package. VAPID keys securely identify our server to browser vendors (Chrome/Safari). Subscriptions are stored in MongoDB.

⏱️ Cron Jobs

`node-cron` runs every minute in `server.js` to check for scheduled announcements. If the time matches, it publishes them and fires notifications.
